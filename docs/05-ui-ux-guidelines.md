# 05 - توجيهات تصميم الواجهة (UI/UX)

## 1. المبادئ العامة

| المبدأ | التطبيق |
|---|---|
| اللغة | عربي بالكامل (RTL). |
| الجوال أولاً | Mobile-first، الأولوية لشاشة 360px-414px. |
| PWA | تطبيق ويب تقدمي قابل للتثبيت على الشاشة الرئيسية. |
| الجمالية | تصميم عصري، احترافي، أنيق. |
| السرعة | تفاعل خفيف، لا تأخير محسوس. |
| الوضوح | كل زر له هدف واحد واضح. |
| الانسجام | نظام تصميم موحد (Tokens / Theme). |

## 2. اتجاه RTL

- HTML attribute: `dir="rtl"`.
- Tailwind: تفعيل `direction-rtl` أو استخدام `rtl:` variants.
- Ionic: تفعيل RTL عبر إعدادات.
- الأيقونات الاتجاهية تُعكس (سهم رجوع، forward...).
- الأرقام عربية (٠-٩) أو إنجليزية حسب تفضيل، الافتراضي **إنجليزية للأرقام المالية** للوضوح.

## 3. الخطوط

- خط أساسي عربي: **Tajawal** أو **IBM Plex Sans Arabic** أو **Noto Naskh Arabic**.
- خط الأرقام: نفس الخط الأساسي إذا داعم، وإلا fallback لخط نظيف.
- أحجام:
  - عناوين كبيرة: 22-24px.
  - عناوين فرعية: 18px.
  - نص أساسي: 15-16px.
  - نص ثانوي: 13-14px.

## 5. مكونات أساسية

### بطاقات Dashboard
- زوايا مدورة 16-20px.
- ظل خفيف.
- أيقونة + رقم كبير + وصف.
- أنيميشن دخول لطيف.

### الأزرار
- زر رئيسي ممتلئ، زر ثانوي محدود الحدود، زر خطر أحمر.
- ارتفاع 44-48px (مناسب للمس).
- أيقونة + نص.
- حالات: idle / hover / loading / disabled.

### الحقول
- حواف واضحة، تركيز ملون.
- Placeholder عربي.
- رسائل خطأ تحت الحقل.
- دعم لوحة الأرقام للجوال (`inputmode="decimal"`).

### القوائم
- بطاقات أو صفوف.
- عند النقر: يفتح صفحة تفاصيل أو Sheet.
- سحب لليمين/اليسار للإجراءات (في الجوال).

### الجداول (شاشات كبيرة)
- بسيطة، صفوف متباعدة.
- في الجوال: تتحول إلى بطاقات.

### Sheets / Modals
- Bottom sheets للجوال.
- Center modals للديسكتوب.

## 6. الحركات (Animations)

- استخدام Framer Motion أو CSS transitions بسيطة.
- ظهور البطاقات بسلاسة (fade + translate).
- زر loading spinner.
- انتقالات صفحات Ionic native-feel.
- تجنب الحركات المبالغ فيها التي تبطئ التجربة.

## 7. التنقل (Navigation)

- Bottom Tab Bar في الجوال (3-5 تبويبات أساسية).
- Side Drawer (قائمة جانبية) للأدوات الإضافية.
- Header مع زر رجوع وعنوان الصفحة.
- التبويبات تختفي/تظهر حسب الصلاحيات.

اقتراح Tabs الأساسية:
```text
1. الرئيسية (Dashboard)
2. العملاء
3. البيع / الدخل
4. التجار / المشتريات
5. المزيد (مصاريف، تقارير، إعدادات...)
```

## 8. لوحة التحكم (Dashboard)

محتوى مقترح:
- بطاقة دخل اليوم.
- بطاقة خرج اليوم.
- بطاقة صافي اليوم.
- بطاقة عدد العملاء عليهم ديون.
- بطاقة تنبيهات (تجاوز سقف، انخفاض شراء).
- زر سريع: بيع سريع، إضافة دين، تسجيل سداد.

البطاقات تُعرض حسب صلاحيات المستخدم.

## 9. شاشات حساسة

### شاشة بيع تفصيلي
- زر إضافة صنف بحجم كبير.
- لوحة أرقام مدمجة.
- مجموع كبير في الأسفل.
- زر حفظ ثابت.

### شاشة إضافة دين
- اختيار عميل (بحث + قائمة).
- مبلغ كبير.
- حقل تفاصيل نصية حر.
- إذا تجاوز السقف: تنبيه أحمر + خيارات.

### شاشة سداد
- اختيار عميل.
- مبلغ.
- ملاحظات.

### شاشة كشف حساب
- تايم لاين عمودي.
- Debt = أحمر ، Payment = أخضر.
- مجموع نهائي بارز.

## 10. الإيصالات والطباعة

- صيغة بسيطة، أبيض وأسود، خط مقروء.
- اسم البقالة + الرقم + التاريخ.
- التفاصيل في وسط.
- مجموع كبير في النهاية.
- زر "طباعة" يستخدم window.print() مع CSS Print خاص.

## 11. الإشعارات

- جرس في الهيدر مع badge للعدد.
- شاشة قائمة إشعارات: غير مقروء بارز، مقروء باهت.
- ضغط الإشعار يأخذ للمصدر.

## 12. زر واتساب

- لون أخضر واتساب.
- أيقونة واتساب.
- عند الضغط: يفتح `https://wa.me/<phone>?text=<encoded message>`.
- يسجل في الباكند أن الرسالة فُتحت.

## 13. الحالات

| الحالة | UI |
|---|---|
| Loading | Skeleton أو Spinner لطيف. |
| Empty | رسم/أيقونة + نص + زر إجراء. |
| Error | رسالة + زر إعادة محاولة. |
| Success | Toast أخضر قصير. |
| Forbidden | رسالة مهذبة "لا تملك صلاحية..." |

## 14. الوصولية (Accessibility)

- تباين ألوان كافٍ (WCAG AA).
- أحجام لمس ≥ 44px.
- aria-labels عربية للأزرار الأيقونية.
- التركيز (focus) واضح.

## 17. مكوّن `<Can />`

```tsx
<Can permission="customers.delete">
  <Button danger onClick={handleDelete}>حذف</Button>
</Can>
```

- يقرأ من store الصلاحيات الحالية.
- إذا غير موجودة → لا يعرض الـ children.
- يدعم `permissions={['a', 'b']}` و `mode="any" | "all"`.

## 18. حالات Edge

- شبكة مقطوعة: شاشة "لا يوجد اتصال" واضحة.
- Token منتهي: refresh تلقائي مرة، إذا فشل → logout.
- صلاحية مفقودة بعد تحديث: 403 → toast "تغيرت صلاحياتك، الرجاء إعادة الدخول".
