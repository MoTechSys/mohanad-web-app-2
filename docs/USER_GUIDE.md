# دليل الاستخدام — دفتر البقالة

<div dir="rtl">

## 1. أول تشغيل
1. ثبّت `app-arm64-v8a-release.apk` (أو `armeabi-v7a` للأجهزة القديمة) — الإصدار 2.1.0.
2. افتح **المزيد ← هوية المحل والطباعة** وأدخل: الشعار، اسم المحل، اسمك، الهاتف، العنوان، البيان العلوي (مثل: «أهلاً بكم — نخدمكم من 7 صباحًا»)، البيان السفلي (مثل: «البضاعة المباعة لا تُرد»). اضغط **حفظ**.
3. (اختياري) **المزيد ← الإعدادات**: العملة، هدف البيع اليومي، حد تنبيه المعاملات الكبيرة، طريقة حساب الربح، رمز PIN، المظهر.

## 2. الأصناف والباركود
- **المزيد ← الأصناف ← +**: الاسم، الباركود (اضغط أيقونة الكاميرا لمسحه)، سعر الشراء، سعر البيع، الكمية الافتتاحية، حد النقص، **تاريخ انتهاء الصلاحية** (اختياري — اتركه فارغًا للمواد غير الغذائية).
- لا يوجد باركود على المنتج؟ اتركه فارغًا — التطبيق يولّد كودًا داخليًا يظهر على الملصق ويُمسح من الكاشير.
- **طباعة ملصقات**: أيقونة الطباعة في أعلى شاشة الأصناف (كل الأصناف) أو من قائمة الصنف (صنف واحد بعدد نسخ). اختر الحجم ثم **طباعة** أو **مشاركة PDF**.

## 3. الكاشير (البيع السريع)
1. من الرئيسية اضغط **الكاشير** (الزر الأخضر).
2. امسح الأصناف بالكاميرا أو بقارئ الباركود — كل مسح يُصدر صوتًا ويزيد الكمية تلقائيًا.
3. اضبط الكمية/الخصم إن لزم، ثم **نقدي** أو **آجل** (اختر العميل).
4. بعد الحفظ تظهر رسالة مع زر **إيصال**: اختر إيصال 80mm أو فاتورة A4 → مشاركة / طباعة / حفظ.

## 4. العملاء (الديون)
- **العملاء ← عميل جديد**: الاسم، الهاتف، حد الائتمان، رصيد افتتاحي (دين سابق).
- داخل العميل: **دين** / **سداد** / **تسوية** / **تصفية الرصيد**. كل حركة تُسجَّل مع الرصيد قبل وبعد.
- **كشف حساب PDF**: أيقونة التصدير أعلى شاشة العميل (كامل أو هذا الشهر) — أرسله للعميل عبر واتساب مباشرة.
- تجميد عميل يمنع الدين الجديد ويسمح بالسداد. تجاوز حد الائتمان يطلب موافقتك.

## 5. الموردون والمشتريات
- **التجار ← تاجر جديد** ثم **مشتريات جديدة**: نقدي (يُسجَّل مصروف تلقائيًا) أو آجل (يزيد دين المورد).
- المشتريات المفصّلة (بنود + مسح باركود) ترفع المخزون وتحدّث سعر التكلفة.
- **سداد المورد** من شاشة المورد؛ كشف حساب PDF من أيقونة التصدير.

## 6. المصروفات والدخل اليومي
- **المزيد ← المصروفات**: مبلغ، فئة، تفاصيل. الفئات قابلة للإضافة.
- **الدخل اليومي**: لتسجيل إجمالي بيع اليوم دون فواتير (للمحلات التي لا تُفوتِر كل عملية).

## 7. التقارير
- **المزيد ← التقارير**: رقاقات **اليوم / هذا الأسبوع / هذا الشهر / الشهر الماضي / تقرير شهري… / آخر 90 يوم / آخر سنة / فترة مخصصة**.
- **تقرير شهري…** يعرض شبكة آخر 24 شهرًا — اختر الشهر.
- أيقونة التصدير أعلى الشاشة: **PDF للفترة**، **Excel للفترة**، **PDF المخزون**، **Excel العملاء**.
- كل ملف يحمل شعارك وبيانك العلوي والسفلي.

## 8. الحماية والنسخ الاحتياطي
- **PIN**: من الإعدادات؛ يُطلب عند كل فتح للتطبيق.
- **النسخ الاحتياطي**: **المزيد ← النسخ الاحتياطي ← تصدير** ينتج ملف JSON شاركه إلى درايف/واتساب. **الاستيراد** يستبدل البيانات بعد تأكيد — الملفات التالفة تُرفض دون مسح.
- **سجل التدقيق**: كل عملية إنشاء/إلغاء/تعديل إعدادات مسجّلة بالوقت.

## 9. وحدات العبوة (كرتون / جوتة / قرطاس)
- في نموذج المنتج اضغط **إضافة عبوة**: الاسم (مثل «كرتون»)، العامل (مثل 24 حبة)، وسعر بيع/شراء اختياري.
- في الكاشير والمشتريات اختر الوحدة من القائمة — المخزون يُخصم بدقة تلقائيًا.

## 10. سندات القبض والصرف
- **المزيد ← سندات القبض والصرف ← +**: اختر قبض أو صرف، الطرف (عميل/مورد أو اسم يدوي)، المبلغ، الطريقة.
- سند القبض من عميل **ينقص دينه تلقائيًا**؛ سند الصرف لمورد يسدد ديننا.
- من قائمة السند: **طباعة A5** رسمية (بالتفقيط العربي) أو **إيصال 80mm** أو **إرسال SMS للعميل** أو مشاركة PDF.
- الإلغاء بسبب فقط — يعكس كل الآثار ولا يحذف السجل.

## 11. رسائل SMS للعملاء
- **تلقائي**: عند بيع آجل يصل العميل SMS بمبلغ الفاتورة وإجمالي دينه (إن كان له رقم هاتف).
- **من السند**: زر «إرسال SMS» يبلغ العميل بالمبلغ المسدد والمتبقي.
- **تذكير بالدين**: من ملف العميل ← القائمة ← «تذكير بالدين عبر SMS».
- أول مرة سيطلب التطبيق صلاحية إرسال الرسائل — اقبلها.

## 12. ورديات الصندوق (تقرير Z)
- **المزيد ← ورديات الصندوق ← فتح وردية**: اسم العامل + النقد الافتتاحي بالدرج.
- في نهاية الدوام: **إغلاق الوردية** — أدخل النقد المعدود فعليًا؛ يظهر لك المتوقع والفرق (زيادة/عجز) قبل التأكيد.
- بعد الإغلاق: **طباعة تقرير Z** حراري 80mm يفصّل: مبيعات نقدية، سدادات، مقبوضات، مصروفات، المتوقع، المعدود، الفرق — مع خانتي توقيع.

## 13. تنبيهات الصلاحية
- المنتجات التي تنتهي خلال 30 يومًا تظهر بوسم برتقالي «ينتهي خلال N يوم»، والمنتهية بوسم أحمر «منتهي».
- تنبيه في لوحة التحكم يجمعها — اضغطه للانتقال لشاشة المنتجات.

## 14. النسخ اليومي التلقائي
- التطبيق يحفظ **نسخة تلقائية عند أول تشغيل كل يوم** ويحتفظ بآخر **7 نسخ**.
- تجدها في **المزيد ← النسخ الاحتياطي** (قسم «النسخ اليومية التلقائية») — انسخ أي نسخة للحافظة أو استعد منها مباشرة.
- ما زلنا ننصح بمشاركة نسخة لواتساب/درايف أسبوعيًا (لو ضاع الهاتف نفسه).

## 15. أسئلة شائعة
- **لماذا لا يمكن حذف فاتورة؟** الحذف يفسد الأرصدة. استخدم **إلغاء** — يعكس الأثر ويُبقي السجل.
- **الطابعة الحرارية؟** استخدم إيصال 80mm ← **طباعة** — يفتح حوار الطباعة الأندرويد؛ ثبّت تطبيق خدمة الطباعة الخاص بطابعتك (بلوتوث/واي فاي).
- **الإدخال الصوتي؟** اضغط أيقونة الميكروفون في لوحة مفاتيح الهاتف داخل أي حقل نص.
- **الحجم؟** ~13MB لأن التطبيق يضم محرك PDF وقارئ الباركود بلا حاجة للإنترنت.
