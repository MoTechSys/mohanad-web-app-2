## المزايا

### الكاشير (نقطة البيع) — «طق طق طق»
- مسح الباركود بالكاميرا (ML Kit) أو بقارئ USB/بلوتوث (HID) أو كتابته يدويًا
- صوت + اهتزاز عند كل مسح، زيادة الكمية تلقائيًا عند تكرار الصنف
- بحث عربي متسامح مع الأخطاء الإملائية (أ/ا، ة/ه، ى/ي + مسافة تحرير محدودة)
- أصناف سريعة (الأكثر بيعًا)، خصم، بيع نقدي أو آجل على عميل
- إيصال 80mm / فاتورة A4 فورًا بعد البيع (مشاركة/طباعة)

### وحدات متعددة للمنتج (م1)
- كرتون / جوتة / قرطاس / كيس… لكل عبوة عامل تحويل وسعر بيع/شراء اختياري
- البيع والشراء بأي وحدة مع خصم المخزون بدقة (أجزاء الألف)
- ضوابط: منع البيع فوق المخزون (يجمّع بنود نفس الصنف)، تحذير البيع تحت التكلفة، تحديث سعر الشراء من الفاتورة

### سندات القبض والصرف (م2)
- ترقيم تسلسلي لا يتكرر (RV-/PV-)، لعميل/مورد أو جهة خارجية
- طباعة A5 رسمية بالمبلغ رقمًا **وكتابةً (تفقيط عربي)** + نسخة حرارية 80mm
- **SMS مباشر من التطبيق** (SmsManager بلا فتح تطبيق الرسائل): إشعار بيع آجل، إشعار سداد، تذكير بالدين

### ورديات الصندوق + تقرير Z (م3)
- فتح وردية (عامل + رصيد افتتاحي) — واحدة مفتوحة كحد أقصى
- إغلاق بجرد فعلي: المتوقع يُحسب من الدفاتر **ويُجمَّد** — الفرق (زيادة/عجز) موثّق
- طباعة إيصال Z حراري 80mm + مشاركة PDF

### تواريخ الصلاحية (م4)
- تاريخ انتهاء اختياري لكل منتج + وسم «منتهي»/«ينتهي خلال N يوم» على بطاقة المنتج
- تنبيه في لوحة التحكم (نافذة 30 يومًا) ينقل لشاشة المنتجات

### نسخ احتياطي يومي تلقائي (م5)
- نسخة كاملة عند أول تشغيل كل يوم — **الاحتفاظ بآخر 7 فقط**
- استعادة بتأكيد (مع تحذير إن كانت هناك وردية مفتوحة)

### تجربة مبسّطة + نسخ بنمط واتساب + إشعارات (م6)
- **نسخ مضغوطة `.glbak`** في مجلد مرئي بمدير الملفات: `Android/media/com.groceryledger.accounts/دفتر البقالة/Databases/` — بلا أذونات تخزين على أندرويد 11+، ونسخ JSON القديمة تُستعاد بلا مشاكل
- زر «نسخ احتياطي الآن» + نافذة استعادة فورية بقائمة النسخ (التاريخ + الحجم)
- **إشعار أندرويد** في شريط الإشعارات للمنتجات المنتهية/القريبة من الانتهاء (قناة `grocery_alerts`)
- «حفظ في الجهاز» يحفظ في `Download/دفتر البقالة/` عبر MediaStore
- **تقرير الأرباح الشهري PDF** + **معاينة** لكل تقرير قبل الطباعة/المشاركة
- خيارات مرونة: **إخفاء ماسح الباركود** (لمحلات بلا باركود) و**خط أكبر** (+15%) لكبار السن
- شاشة «المزيد» شبكة أيقونات كبيرة ملوّنة؛ هوية زرقاء مالية

### الدفاتر (append-only)
- **العملاء**: دين، سداد، تسوية، رصيد افتتاحي، حد ائتمان، تجميد، فترة سماح، كشف حساب
- **الموردون**: مشتريات آجلة، سداد، كشف حساب
- **المبيعات / المشتريات**: إجمالي فقط أو بنود مفصّلة، إلغاء يعكس الأثر دون حذف
- **المصروفات** بفئات، **الدخل اليومي**، **المخزون** بتكلفة وتنبيه نقص
- كل حركة تحفظ `الرصيد قبل / بعد` — الأرصدة تُشتق من الدفتر وليست حقلًا قابلًا للتلاعب
- سجل تدقيق، تنبيه المعاملات الكبيرة، حماية PIN

### هوية المحل على كل مطبوعة
من **المزيد ← هوية المحل والطباعة**: الشعار، اسم المحل، المالك، الهاتف، العنوان، **البيان العلوي** و**البيان السفلي** — تُطبع على كل فاتورة وإيصال وكشف وتقرير وملصق.

## البنية

```
lib/
├─ main.dart                 نقطة الدخول، بوابة PIN، النسخ اليومي، إشعار الصلاحية
├─ app/                      AppServices (تجميع الخدمات)، AppShell (التبويبات)
├─ core/
│  ├─ money/                 Money (قرش صحيح) و Qty (جزء من ألف) — بلا أعداد عشرية
│  ├─ platform/              NativeBridge (صوت/اهتزاز/روابط/اتصال/SMS/إشعار/حفظ) عبر MethodChannel
│  ├─ theme/  utils/  widgets/  (ماسح الباركود، محرّر البنود، أزرار التصدير، تفقيط)
├─ domain/
│  ├─ enums/                 PaymentType, DocMode, RefType, ProfitMode, VoucherType…
│  └─ models/                Customer/Supplier/PartyTx, Sale/Purchase/Expense, Product/StockMove,
│                            Voucher, CashSession/ZReport, AppSettings
├─ data/
│  ├─ kv_backend.dart        Hive أو Memory (للاختبارات)
│  ├─ ledger_db.dart         الحالة الكاملة + الاشتقاقات (أرصدة، مخزون، فهرس باركود)
│  ├─ services/              Party / Document / Inventory / Report / Settings / Voucher /
│  │                         CashSession / Sms / Backup
│  └─ export/                PdfBrand, PdfExporter, ExcelExporter, ShareService
└─ features/                 شاشة لكل ميزة (pos, dashboard, customers, suppliers, sales,
                             purchases, expenses, daily_income, products, vouchers, shifts,
                             reports, settings, more)
android/app/src/main/kotlin/com/groceryledger/accounts/MainActivity.kt   الجسر الأصلي
```

**قواعد المحرك** (تُختبر آليًا في `test/domain/`):
- لا حذف لحركات مالية — إلغاء فقط مع عكس الأثر
- `balanceAfter` لكل حركة = `balanceBefore ± amount` وتساوي رصيد الطرف المشتق
- الفاتورة الآجلة تُنشئ حركة دين مرتبطة (`refType = sale`) لا يمكن إلغاؤها مباشرة
- المشتريات النقدية تُنشئ مصروفًا مرتبطًا؛ الإلغاء يتعاقب
- التصدير ← المسح ← الاستيراد يُعيد الأرصدة والورديات بدقة (لا «أشباح»)
- «إجمالي الداخل» في تقرير الفترة يطابق تقرير Z (سندات القبض الخارجية مشمولة في كليهما)
